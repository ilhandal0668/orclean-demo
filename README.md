# ORCLEAN — Yeni Web Sitesi Tasarım Demosu

Bu depo, ORCLEAN için hazırlanan yeni web sitesinin **tıklanabilir tasarım
demosunu** barındırır. Amaç, siteyi yayına almadan önce sizin incelemeniz ve
eksik gördüğünüz noktaları bize iletmenizdir.

## Demoyu açın

👉 **https://ilhandal0668.github.io/orclean-demo/**

> Depo yayınlandıktan sonra bu adres çalışır duruma gelir.
> Bilgisayarınıza hiçbir şey kurmanız gerekmez; bağlantıya tıklamanız yeterli.

## Neye bakmanızı rica ediyoruz

| Alan | Neyi kontrol edin |
|---|---|
| Ana sayfa | Bölümlerin sırası, metinler, görseller, öne çıkan makineler |
| Ürün listesi | Kategoriler, makine adları, kapak görselleri |
| Ürün detayı | Teknik özellikler, açıklama metni, görseller — **veriler doğru mu?** |
| Kurumsal | Şirket metni, rakamlar, vurgular |
| İletişim | Telefon, adres, çalışma saatleri, e-posta |
| Mobil görünüm | Telefonunuzdan da açıp bakın |

## Bu demoda çalışmayan iki şey

Demo, sitenin **statik** bir kopyasıdır (sunucu tarafı çalışmaz):

- **Ürün arama** — üstteki arama kutusu sonuç getirmez
- **İletişim formu** — gönderim yapmaz

İkisi de canlı sitede sorunsuz çalışmaktadır; yalnızca bu önizleme kopyasında
devre dışıdır. Sayfanın altındaki bilgi şeridi de bunu hatırlatır.

Demoda yer verilmeyenler: sepet / ödeme / hesabım sayfaları (site bir **teklif
kataloğu** olarak kurgulandı, çevrimiçi satış yoktur).

## Eksikleri bize nasıl iletirsiniz

**Yöntem 1 — GitHub üzerinden (tercih edilen):**
Üstteki **Issues** sekmesine gidip **New issue** deyin. Hazır bir form açılacak;
her eksik için ayrı bir kayıt açmanız, neyin çözüldüğünü takip etmemizi
kolaylaştırır.

**Yöntem 2 — Kontrol listesi:**
GitHub hesabınız yoksa [`KONTROL-LISTESI.md`](KONTROL-LISTESI.md) dosyasını
indirip üzerine notlarınızı yazın ve bize geri gönderin.
